# Roadmap

## Complete Phase 1 validation

Run the Windows acceptance matrix, inspect idle CPU and burst-copy behavior,
validate app compatibility for PrintWindow and paste, assess keyboard/screen-reader
navigation and both themes at high DPI. Stabilize packaging only after these pass.
No release, installer, auto-update system or AI is part of this draft.

## Phase 2 (intentionally not implemented)

- Screenshot region capture and optional Windows Graphics Capture backend.
- OCR and searchable screenshot contents.
- URL extraction and deeper, consent-aware document context.
- Automatic activity sessions and tags.
- Richer code recognition and a Code filter.
- Semantic search with optional local embeddings.
- Local AI session names/summaries, if explicitly enabled later.

All future features retain local-first operation and exclusion precedence.
